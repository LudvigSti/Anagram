# Anagram Grouping Program

This is a simple Kotlin program that reads words from a text file and groups them by anagram similarity. Words that are anagrams of each other are printed together.

# Big O Notation

n = number of words
k = word length
l = number of unique letters in word

Sorting Method: 

O(n · k log k)

Frequency Method

O(N · (k + l log l))
